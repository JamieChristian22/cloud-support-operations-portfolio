# Recruiter Quick Start

## 60-Second Review Path
1. Read the root `README.md`.
2. Review Project 1's `INC-001-ec2-ssh-failure.md` for ticket ownership and AWS troubleshooting.
3. Review Project 3's incident set for DNS, routing, port, cloud-firewall, and host-firewall troubleshooting.
4. Review Project 4's incident and postmortem for monitoring, triage, escalation, RCA, and corrective actions.
5. Review Project 5 for IAM, backup/recovery, administration, and compliance checks.

## Hiring Signals Demonstrated
- Tier 1/Tier 2-style cloud ticket ownership
- EC2, S3, IAM, VPC, CloudWatch, Route 53
- AWS/Azure/GCP service awareness
- DNS, routing, firewall, Security Group, NSG, and host-level troubleshooting
- Monitoring, log analysis, incident response, RCA, and postmortems
- Least-privilege IAM/RBAC
- Backup verification and restore procedures
- Linux shell, Python, JSON policy, Terraform, and operational documentation

## Evidence Integrity
Tickets, logs, transcripts, metrics, and diagrams are reproducible portfolio lab artifacts. They are not represented as employer production records or live customer exports.
