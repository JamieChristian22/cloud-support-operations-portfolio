# 🔎 Troubleshooting Methodology

The projects use a consistent cloud support methodology.

### 1. Identify the Issue

Review the ticket, alert, symptoms, affected resource, and reported business impact.

### 2. Establish Scope

Determine whether the issue affects:

* One user
* One resource
* One application
* One cloud service
* Multiple systems

### 3. Investigate

Inspect relevant:

* Configuration
* Permissions
* Logs
* Metrics
* Networking
* Operating-system state
* Cloud services
* Application health

### 4. Isolate the Root Cause

Use evidence to distinguish the visible symptoms from the underlying technical failure.

### 5. Resolve

Apply the smallest appropriate corrective action while considering security and operational impact.

### 6. Validate

Confirm that the affected service or user workflow functions normally after remediation.

### 7. Document

Record:

* Problem
* Business impact
* Investigation
* Root cause
* Resolution
* Validation
* Preventive recommendations
