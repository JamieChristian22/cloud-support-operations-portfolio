# Security & Evidence Standard

1. **No secrets:** no passwords, API keys, private keys, tokens, or customer data.
2. **No fabricated production claims:** lab artifacts are explicitly identified as lab evidence.
3. **Reproducibility over decoration:** commands, policies, scripts, logs, metrics, runbooks, and configuration let reviewers inspect the troubleshooting logic.

## Adding Personal Live-Cloud Evidence
When these scenarios are run in a personal cloud account, screenshots can be added without changing the structure. Capture the failure, investigation, corrected configuration, and successful validation. Redact account IDs, email addresses, tokens, and other sensitive values.
